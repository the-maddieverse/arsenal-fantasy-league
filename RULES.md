# Arsenal Fantasy League Rules

- Squad size: exactly 6 Arsenal players (1 GKP, 2 DEF, 2 MID, 1 FWD)
- Budget: league default £45.0m (commissioner can adjust before league starts)
- Captain bonus: captain points are doubled; if captain plays 0 minutes, vice-captain is doubled
- Transfers: 1 free transfer each gameweek, roll over max 2, each extra transfer costs 4 points
- Deadlines: all editing locks at gameweek deadline; snapshots are immutable and used for scoring
- Starting gameweek: only gameweeks at/after selected start are counted
- Tie-breakers: gameweek wins, cumulative captain points, fewer transfer deductions, then shared rank
